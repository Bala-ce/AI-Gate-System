# 🔥 PROJECT OVERVIEW

You are building an:

> **AI-Based Smart College Bus Entry & Exit Monitoring System**

### 🎯 What Your System Will Do

1. Detect bus number (like 66, 68) from front sticker
2. Log:

   * Bus ID
   * Bus Number
   * Date
   * In-Time
3. When bus exits:

   * Update Out-Time
4. Store data:

   * Local system
   * Cloud database
5. Generate:

   * Daily PDF report
   * Monthly statistical report
6. Detect unknown vehicles:

   * Capture vehicle number plate
   * Store entry & exit time

This is a **complete AI surveillance + automation system**.

---

# 🏗 SYSTEM ARCHITECTURE

## 📷 1. Hardware Setup

* 2 CCTV Cameras

  * Camera 1 → Incoming lane
  * Camera 2 → Outgoing lane
* Local PC / Mini Server (Gate system)
* Internet connection
* Cloud storage

---

# 🧠 2. AI / Software Components

## A. Bus Number Detection (Sticker Recognition)

Since:

* Sticker position is fixed
* Font style same
* Numbers unique

You can use:

### Option 1 (Easy & Accurate):

* OpenCV + ROI cropping
* EasyOCR / Tesseract OCR

### Option 2 (Advanced):

* Train a custom YOLO model to detect number region

---

## B. Unknown Vehicle Detection (Number Plate Recognition)

For unknown cars:

* Use YOLO for vehicle detection
* Use OCR for number plate reading
* Store in "Unknown Vehicles" table

You can use:

* YOLOv8
* OpenALPR
* EasyOCR

---
